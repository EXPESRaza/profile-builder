# Profile Builder

A single-page chat app that builds a durable travel profile through conversation.
Take-home exercise for Atlas (Full-Stack Engineer).

> Work in progress — full setup instructions, design decisions, and known gaps
> will be filled in as the implementation lands. See `PROCESS.md` for the
> annotated build log.

## Quick start

```bash
npm install
cp .env.example .env.local   # then set OPENAI_API_KEY
npm run dev                  # http://localhost:3000
```
